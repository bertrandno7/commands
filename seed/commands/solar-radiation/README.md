# SolarRadiation

Estimate cumulative solar radiation and preliminary photovoltaic yield with context shading.

This is an imported draft reconciled with the executable source in COMMANDS commit `044050f`. The source license still requires an explicit author declaration before production reuse.

## Runtime

- Rhino 7 and 8
- Rhino Python
- Entrypoint: `src/main.py` → `run_command`

## Capabilities

- Cumulative solar exposure
- Weather-data input and context shading
- Preliminary photovoltaic-yield estimate

## Permissions

- `document.read`
- `document.write`
- `network`
