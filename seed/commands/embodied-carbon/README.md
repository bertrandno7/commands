# EmbodiedCarbon

Estimate embodied carbon by structure, facade, reuse, and new construction.

This is an imported draft reconciled with the executable source in COMMANDS commit `044050f`. The calculation is transparent and suitable for rapid option comparison; project decisions still require verified quantities and factors. The source license remains unresolved.

## Runtime

- Rhino 7 and 8
- Rhino Python
- Entrypoint: `src/main.py` → `run_command`

## Capabilities

- Factor-based carbon estimate
- Reuse and new-build split
- Option-ready breakdown

## Permissions

- `document.read`
- `document.write`
