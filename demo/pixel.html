03 / ABOUT THE COMMAND

Geometry is
the output.

Derived directly from M004_pixelate.py in Hark. Cube pixels are aligned to a global Cartesian grid. Tetra uses six conforming Kuhn tetrahedra per world-grid cube. Tri uses equilateral triangular prisms; Stagger uses ABC triangular-prism stacking; CubeStagger shifts every other cubic floor by half a cell in X and Y.

Unlike an image-effect preview, the demo generates actual triangle geometry and provides an OBJ download. Gap = 1 removes internal faces for the conforming modes; smaller gaps keep separate units.

The original Rhino command accepts closed Breps, extrusions and meshes. This browser preview currently samples only the analytic slab, rotated tower and spherical test massing; arbitrary Rhino/Brep import is a separate milestone.
